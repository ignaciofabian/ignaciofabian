## 🔥 Proyectos destacados

### 🛒 [PokéStore — Frontend](https://github.com/ignaciofabian/poke-page-react)

Proyecto académico colaborativo de una tienda de cartas Pokémon, migrada desde un sitio HTML a una aplicación React.

Incluye catálogo con búsqueda y filtros, carrito persistente, gestión de sesión, pedidos de prueba y panel de administración. Utiliza almacenamiento local del navegador y cuenta con pruebas de componentes, rutas y accesibilidad.

**Stack:** `React` · `JavaScript` · `Vite` · `React Router` · `CSS` · `Vitest` · `Testing Library` · `jest-axe`

🔗 [Ver demo en Vercel](https://poke-page-react.vercel.app) · [Código](https://github.com/ignaciofabian/poke-page-react)

### 🔐 [PokéStore — Backend colaborativo](https://github.com/ignaciofabian/poke-page-backend)

Backend en desarrollo realizado en colaboración, con inicio de sesión mediante JWT, middleware de validación de tokens y una ruta de prueba protegida.

Incluye documentación con Swagger UI y configuración de conexión a MongoDB Atlas mediante Mongoose. La autenticación utiliza actualmente usuarios de prueba en memoria.

**Stack:** `JavaScript` · `Node.js` · `Express` · `JWT` · `MongoDB Atlas` · `Mongoose` · `Swagger`

🔗 [Código](https://github.com/ignaciofabian/poke-page-backend)

### 📚 [Library Microservices](https://github.com/ignaciofabian/Library-Microservices)

Sistema de gestión de biblioteca construido con arquitectura de microservicios para usuarios, autenticación, libros y préstamos, con API Gateway / BFF y despliegue mediante Docker Compose.

**Stack:** `Java` · `Spring Boot` · `JWT` · `PostgreSQL` · `Docker Compose`

🔗 [Código](https://github.com/ignaciofabian/Library-Microservices)
